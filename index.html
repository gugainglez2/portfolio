Twitter Clone

Aplicação full-stack que replica as funcionalidades principais de uma rede social, construída com Python e Django. O projeto implementa um sistema completo de Autenticação e CRUD, permitindo que usuários criem perfis, publiquem posts e gerenciem suas informações. Um diferencial técnico é a integração com o Cloudinary para o armazenamento persistente de mídias na nuvem, superando limitações de ambientes efêmeros. A interface foi desenvolvida com Tailwind CSS, garantindo um design moderno, limpo e totalmente responsivo, enquanto o deploy foi otimizado no Render com Gunicorn e WhiteNoise.
