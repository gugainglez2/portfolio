Calculadora de médias

Calculadora de Médias Escolares desenvolvida em JavaScript puro e HTML/CSS. O projeto foi focado na prática de manipulação do DOM (Document Object Model). Implementa lógica de captura e validação de entradas, cálculo modular de média e injeção dinâmica de linhas na tabela, exibindo o status final (Aprovado/Reprovado) baseado em uma nota mínima configurável.

Action Store

Página de e-commerce estática, desenvolvida em HTML5 e CSS Puro, com foco total no Design Responsivo. A página utiliza consultas @media screen com breakpoints específicos para adaptar layouts de Desktop (4 colunas), Tablet (2 colunas) e Mobile (1 coluna). Demonstra proficiência em Flexbox e CSS Grid para construção de layouts dinâmicos e manutenção da experiência do usuário em qualquer dispositivo.

EBAC FLIX

Página promocional para serviço de streaming desenvolvida integralmente com o Bootstrap 5. O foco foi na utilização de componentes prontos para agilizar o desenvolvimento, como a Navbar Fixa e Responsiva (com Toggler), o Carousel para destaque visual e os Cards para exibir planos e formulários. Demonstra o domínio do Sistema de Grid do Bootstrap (col-12, col-md-6, col-lg-4) para garantir a responsividade do layout em todos os dispositivos, do mobile ao desktop.
